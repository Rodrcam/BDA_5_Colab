Demo de Transacciones PostgreSQL

Este formulario inserta un profesor y un curso en la misma transacción usando el decorador @with_transaction. Si se activa "Forzar error", se usará un profesor_id inexistente en el curso, provocando una violación de clave foránea y el rollback de toda la operación.

Código relevante

@with_transaction
def _insert_profesor_y_curso(profesor, curso, *, conn, cursor):
    cursor.execute(SQL_INSERT_PROFESOR, (profesor.id, profesor.nombre))
    cursor.execute(SQL_INSERT_CURSO, (curso.id, curso.nombre, ...))
    # Si alguna falla → conn.rollback() automático
